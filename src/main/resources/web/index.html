How to Play

  • Phase 1 — Placement: Take turns placing up to 3 pieces each on any empty node.
  • Phase 2 — Movement: Once all 3 pieces are placed, select one of your pieces and slide it along a connected line to an adjacent empty node (perimeter neighbors or center).
  • Win or Draw: First player to align 3 in a row wins. Repeated positions (3x) or 50 movement plies end in a draw.
